### 隐私承诺现在由发布关卡守住

`routetest`（29 项）与 `storetest`（18 项）已并入 `deploy-gate.sh`。这两套检查守的是本插件的立身之本：**工具结果里不得出现书名、路径与正文**。

| 检查 | 拦住什么 |
| --- | --- |
| 原始返回值不含正文内容（按正文字符串比对） | 工具结果夹带 `chapter.text` |

## 三处修复的成因

**设置里的「找书」弹窗**：宿主设置面板是 `document.body` 上的 portal，`z-index:1000`；插件的浮层在宿主根节点**内部**，其页面永远压不过设置面板（异常表现：点「找书」看不到弹窗，或一闪即逝）。修复：需要浮在宿主弹窗之上的页面改用 `react-dom` 的 `createPortal` 画到 `document.body`，自带 `z-index:1150` 与阅读器自己的颜色变量（`.sr-float`）。宿主自身也以 `react-dom` 绘制弹窗，`react`/`react-dom` 来自同一份内置模块表，实例一致。宿主在 macOS 上把 `body` 的直接子元素一律设为 `-webkit-app-region:no-drag`，浮层因此天然可点击。设置里打开的书库**属于设置面板**：Escape 先关书库、设置不动；面板一关，书库随之消失，不会留下悬空页面。

**卡片末尾显示不全**：卡片收起时文字被卸载，重新展开的第一帧没有可测量的元素，于是整章余文被画进卡片，再由 `-webkit-line-clamp` 从半行处裁断（表现为行尾一个省略号）。修复：展开后**在浏览器绘制之前**重新测量页面边界（`useLayoutEffect`），并保留上一次测量结果，直到文字能再次被测量；绘制区间因此始终止于行末。

**阅读器的边框整体消失**：`--sr-line` 同时被用作「一行的颜色」和「一行的行高」。面板与卡片把行高写进这个变量，于是所有 `border:… solid var(--sr-line)` 都拿到「1.9」这个非法颜色，整条声明作废，`border-style` 回到 `none`——边框、细分隔线全部不画。修复：行高改名 `--sr-line-height`，颜色仍叫 `--sr-line`；并把三处重复的取色表合成一份（`READER_TOKENS`），其中一处还写着宿主早已不用的 `--dsw-alias-state-warning-primary`，那一块界面一直在用自己的旧颜色。

依赖说明：React 18.2.0 的 UMD 构建来自本机已有项目，副本与 MIT 许可存放在 `verify/dom/vendor/`。测试不下载任何内容，不访问网络。

### 本轮修正的测试替身缺陷

`stealth-reader-crashprobe.mjs` 的 React 替身此前不忠实于 React，掩盖了两类问题：

- 依赖变化时不会执行上一轮 effect 的清理，重复注册的监听会一直累积。
- 回调 ref 每次更换标识都会得到新节点，而 React 会把同一个元素交给新回调。

修正后（依赖变化清理、回调 ref 保持同一元素）暴露出一个真实交互依赖：**面板的滚动监听必须挂在回调 ref 持有的那个元素上**。替身现已支持把探针自己的节点交给回调 ref，滚动场景随之恢复。隔离测试三项覆盖该语义。

## 底栏分档规则（实测得出）

在真实 Chrome 中量得底栏各控件宽度：翻页键 19px、搜索 24px、目录 22px、书库 22px、来源 68px、移到侧栏 19px、进度条+数字 71px、收起 20px；整行不裁剪所需约 333px，章节名最小 54px。

| 档位 | 底栏宽度 | 保留 |
| --- | --- | --- |
| wide | ≥ 400px | 全部：翻页、章节名、进度条+数字、搜索、目录、书库、来源、移到侧栏、收起 |
| medium | ≥ 232px | 去掉进度条、书库、来源、移到侧栏 |
| narrow | ≥ 196px | 再去掉目录（章节名留下，位置比跳转重要） |
| tiny | ≥ 126px | 再去掉章节名 |
| micro | < 126px | 再去掉进度数字 |

留在行内的一律是阅读时真正要用的：翻页、搜索、章节名、收起、进度数字；书库、来源、移到侧栏是极少使用的管理动作，窄卡片上直接不显示——它们在插件的设置页与右侧栏里仍然可用，不另设「更多」按钮。

## 图标按钮的统一规则

规则只写一次，在样式表的 `.sr-ibtn` 与 `.sr-lbtn` 两处：

- 无边框、无底色，灰字；悬停时才出浅底；键盘聚焦时出一圈强调色描边。
- 尺寸由三个变量决定：`--sr-ibtn-size`（点击区）、`--sr-ibtn-glyph`（字形大小）、`--sr-ibtn-radius`（圆角）。
- 每个界面只声明一次自己的比例：卡片底栏 22px/13px/6px，面板 26px/13px/6px，输入框旁的收起条 28px/13px/圆形，输入框工具栏入口 28px/14px/6px。
- 带文字的按钮（找书）用 `.sr-lbtn`：同样高、同样圆角、同样的反应，宽度随文字。

规则由一条测试守着：所有带图标特征的按钮类（`sr-btn`、`sr-strip-open`、`sr-strip-step`、`sr-strip-fold`、`sr-strip-mark`、`sr-strip-bar-btn`）必须同时带 `sr-ibtn` 或 `sr-lbtn`，否则测试失败——以后加图标按钮不会再跑偏。真实浏览器里另有一项检查：底栏所有图标按钮宽高完全一致，带文字的按钮与它们等高。

## 已知功能边界

- 自动适配针对宽度，不是把长页面整段高度缩进一屏；缩放下限 40%。
- 适配只在加载完成后重算一次，动态迟到布局与容器 resize 不触发重算。
- 只有支持 browser bridge 的 Desktop 环境可嵌入站点；普通 Web 环境显示不可用状态。
- 禁止为 UI 验收把真实小说内容、标题、路径或登录数据写入对话、报告或截图交付物；使用受控合成页面。
